# Sitemap Capture Planning

Use this process before taking screenshots for a Kestrel lead report.

## Goal
Avoid homepage-only analysis.
Use the sitemap (or a fallback page inventory) to choose a small, high-value set of pages for review.

## Default planning flow
1. Try to fetch the sitemap index or sitemap XML.
2. If there is no sitemap, inspect robots.txt and primary navigation.
3. Build a capture plan before taking screenshots.
4. Select a small set of pages that best represent:
   - first impression
   - service clarity
   - trust/credibility
   - team/about quality
   - contact / appointment / intake flow
   - mobile conversion experience

## Preferred page set
Aim to review:
- homepage
- primary service page
- about/team/doctor page
- contact/appointment/intake page
- one extra page only if it materially affects trust or conversion

## Selection guidance
Choose pages that help answer:
- Does the site feel credible?
- Is the value proposition clear?
- Is the service framing understandable?
- Does the trust story hold up beyond the homepage?
- Is the conversion path clean?
- Does mobile make the experience better or worse?

## Output in report
Record:
- sitemap source
- pages discovered
- pages selected
- why they were selected

## Notes
Do not expand into a giant crawl by default.
The goal is a focused plan, not exhaustive coverage.
